Artifacts are the outputs a run leaves behind. Some are static media; some are
editable documents with revisions. `/artifacts` and `/agent/artifacts` open the
organization artifact hub; a run's artifacts also stream into the [session
view](/product/session-view).

## The hub

The hub lists files and outputs across the organization. You can filter by run or
by file type. Opening `/agent/artifacts/:id` shows the artifact and, for a
workpiece, its editor.

| Operation | Endpoint |
| --- | --- |
| List, create | `GET`, `POST /api/artifacts` |
| Fetch, content | `GET /api/artifacts/:id`, `/:id/content` |
| Quality status | `GET /api/artifacts/:id/quality` |
| Preview | `GET /api/artifacts/:id/preview` |
| Workpiece, export | `/:id/workpiece`, `/:id/workpiece/export` |
| Archive a run's artifacts | `GET /api/artifacts/runs/:runId/archive` |

## Workpieces

A workpiece is a revisioned editing surface for these kinds:
document, spreadsheet, presentation, or PDF. The editors are bounded, and native
renderers back each format (see [Artifacts and
workpieces](/concepts/artifacts-and-workpieces) and [Shared
packages](/architecture/shared-packages)). Images and videos stay previewable
media, not workpieces.

## Quality receipts

`GET /api/artifacts/:id/quality` reports whether the current artifact revision
has a matching inspection receipt. A later edit changes the revision or subject
digest, so the current version returns `unverified` until it is inspected again.

## Revision proposals

An agent can propose an edit to a workpiece rather than overwrite it. The proposal
waits for a human decision:

<Steps>
  <Step title="A proposal is made">
    A run proposes a workpiece revision. `GET /api/artifacts/:id/proposals`.
  </Step>
  <Step title="A human accepts or dismisses">
    Accept it with `POST /api/artifacts/:id/proposals/:proposalId/accept`, or
    dismiss it with `POST /api/artifacts/:id/proposals/:proposalId/dismiss`.
  </Step>
</Steps>

:::note
Editing is revisioned, so accepting a proposal advances the workpiece to a new
revision rather than destroying the prior one. The published artifact link stays
authenticated and absolute.
:::
