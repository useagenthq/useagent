Everything in UseAgent reduces to a small set of ideas. Hold these four and the
rest of the system reads cleanly.

<Steps>
  <Step title="The backend owns product control">
    Commands, identity, policy, durable records, and delivery live in the
    backend. Sandbox-backed engines and their resident session processes run in
    the workstation. The UI consumes backend snapshots and streams.
  </Step>
  <Step title="The inner loop is rented">
    Provider drivers connect OpenCode, Pi, Codex, and Claude to the same product
    contracts. The direct `chat` engine uses the command lane without a sandbox.
  </Step>
  <Step title="Output is canonicalized">
    Every engine's native output is mapped to provider-neutral canonical events,
    so different engines render through one UI contract. Native frames are kept
    for fidelity.
  </Step>
  <Step title="Privileged work goes through the gateway">
    A run does not receive platform database or reusable provider credentials. It calls
    typed gateway tools that perform privileged work behind short-lived,
    scope-bound capability tokens.
  </Step>
</Steps>
