UseAgent is a self-hostable workspace for coding agents. Give an agent a task,
follow its progress, review changes, and collect the files it produces. Start
from the web app, Slack, the CLI, or an automation.

The backend keeps threads, runs, commands, and event history in Postgres.
Adapters connect that control plane to coding engines and sandbox providers.
Which engines and tools you can use depends on your deployment and connected accounts.

## A few terms

- A **thread** holds an ongoing conversation and its runs.
- A **run** is one execution attempt, with a status and recorded events.
- An **engine** performs the agent's work; an adapter translates its output.
- A **sandbox** provides the remote computer for sandboxed runs. Direct chat
  also exists and does not require one.
- An **artifact** is a published result you can open or download.

Recorded history supports reconnects and recovery, but does not guarantee that
every interrupted task can resume. Recovery depends on the engine session and
sandbox still being available. See [reliability](/features/reliability).
