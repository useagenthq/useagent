# useAgent for students

**What it is:** an AI coworker with its own computer.
**What you'll do today:** run your first thread and build a weekend project.

---

# The idea in one sentence

Describe the result you want. A coding agent does the work in an isolated
cloud computer with a terminal, a browser, and your repositories. You follow
along in one thread and open the files it produces.

---

# The workspace

- **Engines:** Claude Code, Codex, OpenCode, Pi
- **Thread:** durable, scrollable, reloadable
- **Tools:** terminal, browser, GitHub repositories, your team's context
- **Results:** files, previews, artifacts you can open

---

# Get started

1. Sign in at app.useagent.org
2. Connect a model provider in Settings
3. Start a thread and describe the outcome

*(Or self-host: see the Quickstart page.)*

---

# Three weekend projects

1. **Portfolio site** - one page, plain HTML/CSS/JS
2. **Data report** - CSV in, one-page report out
3. **Web app with tests** - small API plus front end, tests run

---

# Project 1: Portfolio site

> Build a single-page portfolio site. Plain HTML, CSS, and a little
> JavaScript. Hero, about, projects grid, contact footer. Responsive,
> dependency-free.

---

# Project 2: Data report

> Here is my CSV. Summarize the trends, find the best- and worst-attended
> events, and write a one-page report with charts. Cite the numbers you used.

---

# Project 3: Web app with tests

> Build a to-do list web app with a small API and a minimal front end. Write
> unit tests for the API, run them, and show me the output.

---

# Review what it built

Open the files, scroll the thread, and ask:

- Did it do what I asked?
- What would I change?
- What did the tests prove?

---

# Keep going

Reply in the same thread to iterate. Self-host with the Quickstart when you
want full control. Share what you built.
