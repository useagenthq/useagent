This page is the workshop deck. Every `---` line starts a new slide when the
source is pasted into [Marp](https://marp.app), [Reveal.js](https://revealjs.com),
or [Slidev](https://sli.dev) - for Marp, add `marp: true` to the frontmatter
of your copy. The timings and project prompts live on the
[Student and campus kit](/getting-started/students) page.

---

# Ship your first agent run

One hour with useAgent. Leave with something you built.

---

# What is useAgent?

You describe a task in plain words. An agent - Claude Code, Codex, OpenCode,
or Pi - does the work on its own cloud computer while you watch.

You keep the thread, the record, and the files.

---

# What a run looks like

- Your prompt becomes a durable command.
- The agent works in a sandbox with a terminal, a browser, and files.
- Every step lands in the thread, live.
- You approve sensitive actions and review what changed.

---

# Sign up, five minutes

1. Go to app.useagent.org and sign up with email and a password.
2. Open the confirmation link in your mail and sign in.
3. Start a thread and pick a model from the Free list.

New accounts get starter credits and sandbox time. No card needed.

---

# Tonight's build

Pick one project. Copy its prompt from the kit page, paste it into a thread,
and steer until it is done.

- A portfolio site
- A data-analysis report from a CSV
- A tiny web app with tests

---

# Project: portfolio site

One page of plain HTML and CSS: your name, a short bio, three project cards,
a contact section.

Done when it opens from a preview artifact and holds up on a phone screen.

---

# Project: data-analysis report

Attach a CSV. The agent explores it in a notebook, charts three findings,
and writes a one-page report.

Done when the notebook runs top to bottom and the report reads in one sitting.

---

# Project: web app with tests

A todo app - add, list, check off, delete - plus a test suite that has to
pass before you call it done.

Done when tests pass and the README's commands work.

---

# While the agent works

- Read the steps as they land in the thread.
- Answer its questions; it asks before it guesses.
- Ask for changes in the same thread. The log keeps everything.

---

# Show and tell

What did your run produce? Show the artifact, name one thing the agent did
well, and one thing you had to correct.
