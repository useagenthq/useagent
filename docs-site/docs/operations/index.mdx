Operations in UseAgent are built around one principle: a release must prove itself
before it ships, and roll back cleanly if it cannot.

## The shape of a safe change

<Steps>
  <Step title="Type-check everything">
    `bun run typecheck` covers the frontend, backend, and shared packages, and
    must pass before a change is done.
  </Step>
  <Step title="Verify in isolation">
    Suites run against a throwaway database so they never disturb a live one.
  </Step>
  <Step title="Certify exact combinations">
    Live journeys name the engine, credential mode, model, sandbox provider,
    runtime generation, and release fingerprint they prove.
  </Step>
  <Step title="Roll back on any failure">
    Stop the candidate, restore the prior immutable image and environment,
    verify health, then reopen admission.
  </Step>
</Steps>
