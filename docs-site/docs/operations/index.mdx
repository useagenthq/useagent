## Before running real work

1. Verify the frontend and backend health.
2. Confirm the selected provider account and sandbox can execute a small task.
3. Check that the gateway and storage paths are configured for your deployment.
4. Verify a published artifact can be opened and downloaded.
5. Take a backup and test restoration to an isolated environment.

These docs describe the checked-in setup and runtime contracts. They do not
certify the configuration or health of an existing hosted deployment.
