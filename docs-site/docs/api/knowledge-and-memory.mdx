The retrieval and procedure surfaces. See [Knowledge and
wiki](/product/knowledge-and-wiki), [Memory hub](/product/memory-hub), and [Skills
and playbooks](/product/skills-and-playbooks) for what each powers.

## Knowledge

| Method | Path | Purpose |
| --- | --- | --- |
| POST | `/api/knowledge/ingest` | Ingest source material. |
| GET / PATCH / DELETE | `/api/knowledge` | List, edit, remove knowledge. |
| POST | `/api/knowledge/search` | Search knowledge. |
| GET / POST / PATCH | `/api/knowledge/documents`, `/:id` | Manage documents. |
| POST | `/api/knowledge/documents/:id/publish` | Publish a document. |
| POST | `/api/knowledge/documents/:id/archive` | Archive a document. |
| GET | `/api/knowledge/documents/:id/revisions` | Document revision history. |
| GET / POST | `/api/knowledge/drafts` | The learning-lane knowledge drafts. |
| POST | `/api/knowledge/drafts/:id/accept` | Accept a draft (publishes and re-indexes). |
| POST | `/api/knowledge/drafts/:id/dismiss` | Dismiss a draft. |

## Wiki

| Method | Path | Purpose |
| --- | --- | --- |
| POST | `/api/wiki/generate` | Start a wiki generation job for a repository. |
| GET | `/api/wiki/generate/:jobId` | Poll a generation job. |

## Memory

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/api/memory/search` | Hybrid search across the personal and org pools. |
| GET | `/api/memory/browse` | List a pool's stored items. |
| GET | `/api/memory/captures` | The capture outbox and its delivery state. |
| GET | `/api/memory/recalls` | The recall ledger. |
| PATCH / DELETE | `/api/memory/item/:id` | Correct or remove an item within a pool. |
| POST | `/api/memory/captures/:runId/retry` | Re-enqueue a dead capture. |
| POST | `/api/memory/captures/:runId/resolve` | Reconcile an orphaned capture, at most once. |

## Skills and playbooks

| Method | Path | Purpose |
| --- | --- | --- |
| GET / POST / PATCH / DELETE | `/api/skills`, `/:id` | Manage skills and playbooks. |
| POST | `/api/skills/:id/run` | Run a skill. |
| POST | `/api/skills/import/scan` | Scan a repository for `SKILL.md` files. |
| POST | `/api/skills/import` | Import selected skills, pinned to a commit. |
| GET | `/api/skills/proposals` | Learning-lane skill-revision proposals. |
| POST | `/api/skills/proposals/:id/accept` | Accept a proposal. |
| POST | `/api/skills/proposals/:id/dismiss` | Dismiss a proposal. |
