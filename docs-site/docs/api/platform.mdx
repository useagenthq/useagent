## GitHub

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/api/repos` | List the organization's repositories. |
| GET | `/api/repos/:owner/:name/branches` | List a repository's branches. |
| GET | `/api/pulls` | Open pull requests across connected repositories. |

## Provider connections

The whole router is user-scoped: without an authenticated user every route
returns `403 user_required`. Creation and update happen only through the
per-provider key route and the OAuth subroutes; the collection root is
read-only.

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/api/provider-connections` | List the current user's connections. |
| POST | `/api/provider-connections/openai/chatgpt-oauth/start` | Begin the managed-account OAuth flow. |
| GET | `/api/provider-connections/openai/chatgpt-oauth/status` | Poll the OAuth flow. |
| POST | `/api/provider-connections/openai/chatgpt-oauth/cancel` | Cancel an in-progress flow. |
| POST | `/api/provider-connections/openai/chatgpt-oauth/revoke` | Revoke the managed account. |
| GET | `/api/provider-connections/:provider` | A provider's connection. |
| PUT | `/api/provider-connections/:provider/api-key` | Store a provider API key (write-only). |
| POST | `/api/provider-connections/:provider/revoke` | Revoke a provider's credential. |

## Terminal and desktop

| Method | Path | Purpose |
| --- | --- | --- |
| WS | `/api/runs/:id/terminal` | A run's interactive terminal (one sandbox PTY per WebSocket connection). |
| ANY | `/api/live-proxy/:threadId/*` | Same-origin bridge to the thread's engine server. The thread id is the root run id and is org-authorized; an unknown or cross-org thread returns 404. |
| WS / HTTP | `/api/desktop-proxy/*` | The noVNC desktop proxy (`websockify`). |
| GET | `/api/desktop-proxy/:threadId/ready` | Desktop readiness. |
